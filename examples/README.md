# Examples

Minimal Vite starters. Open one in StackBlitz, or copy the folder and run `npm install && npm run dev`.

- **svelte** (Svelte 5: `<Page>`, `<Stage>`, `<Figure>`): https://stackblitz.com/github/arbourtrary/flipbook-foundry/tree/main/examples/svelte
- **react** (React 19: `<Page>`, `<Stage>`, `<Figure>`): https://stackblitz.com/github/arbourtrary/flipbook-foundry/tree/main/examples/react
- **vanilla** (plain TypeScript: `createPage`, `createStage`, `wander`, `greet`): https://stackblitz.com/github/arbourtrary/flipbook-foundry/tree/main/examples/vanilla
